# Folder Gambar

Taruh file foto avatar di folder ini dengan nama **`avatar.jpg`** (atau `.png`), lalu pastikan nama file sama dengan nilai `profile.avatar` di `src/data/portfolio.js`.

Contoh yang aktif sekarang: `avatar` = `/images/avatar.jpg` → berarti file yang dibutuhkan adalah `public/images/avatar.jpg`.

> Catatan: file di folder `public/` diakses langsung dari root, jadi path-nya `/images/avatar.jpg`.
